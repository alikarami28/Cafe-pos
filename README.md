# ☕ کافه من - صندوق فروشگاهی

نرم‌افزار تحت وب صندوق فروشگاهی مخصوص کافه، رستوران و کافی‌شاپ

## ✨ امکانات

- 📱 **PWA** - قابلیت نصب روی ویندوز، اندروید و iOS
- 🔌 **آفلاین کامل** - بدون نیاز به اینترنت کار می‌کند
- 📦 **مدیریت محصولات** - افزودن، ویرایش و حذف محصولات با دسته‌بندی
- 🛒 **سبد خرید** - ثبت سریع سفارشات
- 🧾 **پیش‌نمایش فاکتور** - مشاهده و چاپ فاکتور قبل از نهایی شدن
- 📊 **گزارش‌گیری** - گزارش روزانه، هفتگی و ماهانه فروش
- 📥 **خروجی CSV** - دریافت فایل گزارش برای Excel
- 🖨️ **اتصال به پرینتر** - پشتیبانی از پرینتر بلوتوث و USB
- 💾 **پشتیبان‌گیری** - ذخیره و بازگردانی اطلاعات

## 🚀 نصب و اجرا

۱. پروژه را دانلود کنید
۲. فایل `index.html` را با مرورگر باز کنید
۳. برای نصب به عنوان برنامه، از منوی مرورگر گزینه Add to Home Screen را بزنید
